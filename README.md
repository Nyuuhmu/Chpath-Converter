# Chpath-Converter

Converts Driftcity `.chpath` files to `.index` files and vice versa. 
Note that there is a little bit of loss when converting a vanilla `.chpath` to `.index`, then back to `.chpath`. Converted files match another though.

## How to use

Drag any `.chpath` or `.index` file onto the `Chpath-Converter.exe`, the program will convert it into a usable file of the other type.
